# Useage
1. Clone this repository to your `$HOME` directory with

  ```bash git clone https://github.com/Hello-world150/dotfile.git ~```
  > [!CAUTION]
  > Your `~/.config/` directory or `.zshrc` may not be empty. You should back up them.
2. Use with yadm
  - Install yadm;
  - Execute ```bash yadm clone https://github.com/Hello-world150/dotfile.git```.
